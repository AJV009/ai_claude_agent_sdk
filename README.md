# AI Claude Agent SDK

A Drupal module that integrates the Claude Agent SDK into your Drupal site. Provides a terminal interface for interacting with Claude, managed agent skills (synced to `.claude/skills/` on the filesystem), agent profiles, and a Node.js sidecar bridge for real-time streaming.
